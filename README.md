# Zubair 360 — "Your Trusted Tech Guy" Portfolio Website

A complete, high-converting, single-page portfolio website tailored specifically for American small and medium business owners (contractors, bakeries, clinics, lawyers, restaurants, local shops).

### 🎨 Visual Theme (Cyber-Luxe Dark Glassmorphism)
- **Deep Wine-Red to Navy Gradient Atmosphere** (`#18030B` via `#080312` to `#03081A`)
- **Large Frosted Glassmorphism Panel** with 36px rounded corners, translucent borders, and 24px backdrop blur
- **Floating 3D Isometric Magenta Cubes** with smooth animated floating effects
- **Glowing Wireframe Circles & Ambient Light Rings**
- **Neon Cyan & Magenta Typography**
- **100% Plain English**: Zero tech jargon anywhere on the page.

## ⚙️ Quick Customization

### 1. Update Your WhatsApp Number (1-Line Change)
Open `index.html` and search for `WHATSAPP_PHONE_NUMBER`:
```javascript
const WHATSAPP_PHONE_NUMBER = "1234567890";
```
Replace `"1234567890"` with your actual WhatsApp number with international country code (e.g. `"88017XXXXXXXX"`).
All WhatsApp buttons, quote selectors, and links will update automatically!

### 2. Swap Your Profile Photo
Simply replace `avatar.jpg` or `avatar.jpeg` with your own square photo.
