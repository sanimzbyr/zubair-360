## 🚀 How to Deploy on GitHub Pages in 2 Minutes

Because this website is built as a self-contained, production-ready static page, **no build tools, npm, or servers are needed!**

### Step 1: Create a GitHub Repository
1. Go to [GitHub](https://github.com) and click **New Repository**.
2. Name it something like `portfolio` or `zubair360`.
3. Set it to **Public** and click **Create repository**.

### Step 2: Upload Your Files
Upload the following files from `/home/sanimzbyr/.gemini/antigravity/scratch/zubair360-website/` into the root of the repository:
- `index.html` (The complete website)
- `avatar.jpg` (Your profile photo)

### Step 3: Enable GitHub Pages
1. In your GitHub repository, click **Settings** (top right tab).
2. In the left sidebar, click **Pages**.
3. Under **Build and deployment > Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**.
5. Wait 30–60 seconds, and GitHub will give you your live URL: `https://<your-username>.github.io/<repo-name>/`.

## ⚙️ Quick Customization

### 1. Update Your WhatsApp Number (1-Line Change)
Open `index.html` and scroll to line 610 (or search for `WHATSAPP_PHONE_NUMBER`):
```javascript
const WHATSAPP_PHONE_NUMBER = "1234567890";
```
Replace `"1234567890"` with your real WhatsApp international number (e.g., `"88017XXXXXXXX"` or your country code + number with no `+` or spaces).
**All WhatsApp buttons, quote selectors, and footer links across the entire website will automatically update to your number!**

### 2. Swap Your Profile Photo
Simply replace `avatar.jpg` with your own square photo (e.g. 500x500px or 800x800px). The circular frame and warm golden ring will automatically wrap around your photo.
